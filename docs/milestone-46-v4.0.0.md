# 里程碑 46：4.0.0 会员权益、画质增强与海报库

版本：**4.0.0+198**。本里程碑汇总里程碑 45 之后已实现、构建并部署的客户端改动。

## 交付内容

- 会员权益统一检查，支持用户主动开启的本机 7 天体验；保留升级前的画质权益和已有数据。SMB / WebDAV 不限数量，非会员 Emby / Jellyfin 各最多一个连接。批量下载和高级画质入口使用钻石徽标，限制在主动操作时提示。
- 集成固定版本、校验文件完整性的 Anime4K Mode A（Fast），作为会员画质选项；保留上游着色器和 MIT 许可证。切换 FSR / Anime4K 时替换着色器链，异常回退，HDR / RGB 使用兼容路径。
- FSR / Anime4K 输出结构化诊断日志，区分设置成功、渲染配置与 GPU pass 实际执行，并提供 HDC 日志采集脚本。
- 会员购买页压缩说明、折叠详情，价格与购买按钮固定底部；修复播放界面 A/B 按钮在亮色主题下的文字和图标对比度。
- 默认 MPV 硬解档位为「自动（推荐）」；保留手动设置。版本升至 4.0.0，启动页读取真实包版本。
- 完善免费本地海报库：分类搜索、作品聚合、季集排序、详情选集、观看进度、续播、快捷方式添加、增量扫描、取消与错误恢复。读取 NFO / 海报，支持动漫文件名推断和本地缩略图。

详细说明：[会员权益](member-benefits-v1.md)、[Anime4K](anime4k.md)、[渲染诊断](fsr-diagnostics.md)、[4.0.0 海报库与默认设置](release-4.0.0.md)。
