## 初始发现

- SMB 只连接 IPC$ 并返回两条虚假文件提示，未实现共享枚举。

- 支持裸主机、SMB URL、UNC、端口、IPv6 和嵌套起始目录；URL 解码仅发生在地址边界，保留文件名中的百分号、空格、井号和问号。
- stat 改用原生路径 stat，避免把目录当普通文件打开；连接错误保留具体原因；配置页说明服务器根目录与禁止枚举时的直连方法。

- 原生测试夹具不连接 NAS；真实服务器认证策略、共享权限与设备播放仍待用户验收。

### 55 — WebDAV 路径、认证与可靠读取（4.0.0+208）

- 完整 HTTP/HTTPS URL、端口和 IPv6 不再被重复拼接协议头；保留 URL 路径。密码不再被自动 trim，允许公开 WebDAV 使用空凭据。
- 统一编码边界，修复中文、空格、百分号、井号、问号等文件名；解析绝对/相对 href，目录只显示直接子项。
- 以 DAV 命名空间解析 XML，只合并 2xx propstat，支持大文件大小、ISO/HTTP 时间及缺失长度时的 HEAD 补查。错误 HTML、损坏 XML 不再显示为空目录。
- 支持 Basic 和 Digest MD5/SHA-256（包括 sess、auth/auth-int）、保留方法的同源重定向；媒体 GET 可跟随 CDN 地址，但不跨源发送凭据、不从 HTTPS 降级。
- 使用配置子目录探查连接，支持根目录无权限的服务；HTTP 失败保留具体原因，失败连接关闭客户端。
- 范围读取检查 Content-Range、Content-Length 和实际字节数；短读、错位、超长数据明确报错。断开取消所有活动请求，目录 XML 与小文件读取有内存上限，大目录 XML 在 isolate 解析。
- 全套 146 项测试通过，另补充 4 项流/取消回归通过。Digest 对照 RFC 的 MD5 与 SHA-256 已知值；网络测试仅连接本机临时 HTTP 服务。
- 依据：[WebDAV RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html)、[Digest RFC 7616](https://www.rfc-editor.org/rfc/rfc7616.html)、[HTTP RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)。不声称所有 NAS 认证机制均已实测；Kerberos/NTLM WebDAV 认证尚未实现。
- 提交 `7f8c7ca`；签名 HAP 构建成功，规范未签名 HAP 时间戳 `2026-09-09T01:55:07+08:00`。归档 `build/milestones/55-webdav-compatibility/`。

### 56 — 流读取、跨源隔离与大目录性能（4.0.0+209）

- SMB 默认读取上限提升到 1 MiB，并受服务器协商值限制；每条流复用原生缓冲区。8 MiB 测试文件在 1 MiB 协商上限下从 128 次请求降为 8 次，64 KiB 服务器仍使用 128 次。
- 修复 open 成功而 fstat 失败时的句柄泄漏；空文件和读到 EOF 返回空流，远端提前截断明确报错。
- 为工作线程数据流增加连接代次校验，旧流无法读取或关闭重连后重复编号的新读取器；每个 worker 最多 32 条活动流。
- 代理将 URL 绑定到生成时的来源，避免切换服务器串源；重复 URL 复用令牌，令牌表有上限。2 秒、256 项的元数据缓存和请求合并降低播放器探查负担，12 个并发 HEAD 只产生 1 次 stat。
- 字幕匹配由逐媒体扫描整个目录改为一次索引；5000 媒体 + 5001 字幕本机生成约 111–116 ms，已验证链接复用和语言字幕前缀。
- 11 项专项回归及真实 SMB2 回环测试通过；分析无 error / warning。回环使用只读生成数据与测试账户，根目录、中文文件、跨共享、范围及完整 8 MiB 字节校验通过。
- 复现步骤、环境限制和本机性能边界见 `docs/network-library-tests.md`。没有访问用户设备。
- 提交 `9926226`；签名 HAP 构建成功，规范未签名 HAP 时间戳 `2026-09-09T02:15:42+08:00`。归档 `build/milestones/56-network-stream-performance/`。

### 57 — 可恢复浏览与下载版本保护（4.0.0+210）

- 连接/目录错误留在页面，可重试、重连或直接输入已知共享路径；失败不再自动退回或伪装为空目录。下拉刷新、扩展媒体格式识别和有效的复制链接接入浏览器。
- 目录变化仅在请求成功后提交；晚到的旧响应和失败导航不覆盖当前目录、不污染返回历史。连接时间记录失败不会阻塞实际网络浏览。
- 缺失 WebDAV 文件大小时，下载前补查；批量补查最多并发 4 项。显示名不含扩展名时，下载保存保留原始媒体扩展名。
- 下载记录保存 ETag；续传前拒绝同大小但 ETag 已变化的文件。WebDAV 读取对原始来源发送 If-Match 或 If-Unmodified-Since，遇到 412 明确报错；不将 DAV ETag 套用到不同 CDN 资源。
- 暂停/取消会中止仍在等待响应头的连接，不必等到 HTTP 超时；保留已写的续传数据。
- 全套 162 项测试通过，1 项真实 SMB2 测试按默认开关跳过（此前显式启用的回环测试已通过）；包含浏览器组件、并发目录控制、暂停等待响应头和 ETag 替换回归。

### 58 — 边缘协议兼容与 SMB 连接期限（4.0.0+211）

- SMB 改用异步原生连接加工作线程事件循环，为协商/认证设置整体 30 秒期限；超时先销毁上下文再释放回调，避免晚回调访问已释放地址。原生模拟验证超时释放顺序。
- 真实 SMB2 本机回环再次通过签名强制连接、共享枚举和 8 MiB 全字节读取；错误密码和对 SMB2 服务强制加密会失败。错误密码在该 Windows 夹具上不及时响应，旧测试约 5 分钟，新测试约 30 秒；这不是 NAS 认证耗时承诺。
- WebDAV XML 支持 UTF-16 双字节序与 Latin-1 编码声明；中文 Digest 用户名使用扩展头参数。加入 SHA-512-256、sess 和 userhash，已知值按 RFC 7616 报告勘误 4897 验证（原文误用了截断 SHA-512）。
- HEAD 不支持或不返回长度时，用 GET bytes=0-0 探查总长并立刻取消响应体；支持空文件 416 及忽略 Range 但提供长度的服务器。禁止把未知长度当零字节。
- 完整压缩响应不再把压缩后的 Content-Length 误用于解压后的数据；范围压缩仍拒绝，防止错位。目录属性全失败时显示错误。
- 使用真实 OHOS aarch64 编译器验证 C/FFI 结构尺寸与偏移，确认随包原生库导出异步连接符号；没有访问设备。
- 参考：[RFC 7616 勘误 4897](https://www.rfc-editor.org/errata_search.php?rec_status=0&rfc=7616)。

### 59 — 禁止根目录访问时的恢复（4.0.0+212）

- SMB 服务器根目录改为虚拟会话，列出共享时才连接 IPC$；已知共享独立认证，IPC$ 拒绝或枚举失败不再阻止直接进入共享。按需连接同时避免下载重连时多做一次无关的 IPC$ 认证。
- IPC$ 单独保留，八个数据共享的缓存和活动读取保护不变。失败枚举可以重试，不销毁正在读取的其他共享。
- 连接失败页始终提供“打开路径”；WebDAV 改填子目录时会用该目录重新验证连接，支持根目录无权限、子目录可访问的服务。
- 分开处理 SMB URL 的编码路径和起始目录的字面路径，保留中文、百分号及字面 `%20`，阻止起始目录逃出所配置的根。
- SMB 原生 errno 穿过 worker 保留；只有确实不存在的路径返回空结果，权限拒绝与网络故障保持明确错误。
- 完整回归 177 项通过、默认跳过 1 项显式回环测试；静态分析没有 error/warning。
