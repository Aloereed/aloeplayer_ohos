# 里程碑 90：系统投播按钮状态同步

版本：4.0.1+243，包含 87–89 的修复。

用户反馈系统投播按钮一直显示“正在准备投播”。上一版自定义按钮直接读取保存在 @State 中的 PlatformView 对象字段，异步 MethodChannel 回调修改原生对象后，按钮依赖的状态没有可靠的显式刷新路径。

改为原生 CastView 发布准备完成状态，ArkUI 组件订阅后更新独立的 @State ready 和 sessionType，按钮文案、背景、enabled 和会话类型读取同一组状态。组件挂载时立即回放当前值，覆盖准备先完成、按钮后挂载的顺序；组件离开取消订阅，原生视图销毁时置为不可用并清理监听。

保持只有会话激活、Extras 和元数据准备成功后才启用选择器。未绕过初始化错误或提前启用按钮。准备错误继续在 Flutter 页面显示。

验证范围：原生 ArkUI 编译、系统投播桥接测试、APP 内容和归档哈希校验。没有访问用户鸿蒙设备，真机需确认准备完成后按钮变为蓝色“选择投播设备”并能打开系统选择界面。

产物：build/milestones/90-system-cast-state，独立保存 debug HAP 与 release APP。
