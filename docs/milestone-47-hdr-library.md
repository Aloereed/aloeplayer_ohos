# 里程碑 47：原生 HDR 实验输出与视频库交互

版本：**4.0.0+199**。汇总里程碑 46 之后的本轮改动，并提供 APP release 包。

## 交付内容

- 将 media_kit_video 固定到仓库内的本地分支，保留上游许可证、原有输出尺寸与纹理释放修复。
- 新增 OHCodec → ArkUI XComponent Surface 的原生视频输出；绕开 Flutter Texture 和当前 SDK 的 OhosView 纹理合成，Flutter 通过透明区域叠加字幕与控件。Surface ID 使用十进制字符串传递，窗口生命周期按实例校验。
- 原生 HDR 模式关闭控件背景渐变和 Flutter 背景模糊。开关位于播放器设置底部、默认折叠的「实验功能」，默认仍使用普通播放模式。
- 视频库「添加视频」的两个主入口改为紧凑整行按钮；「打开文件」「打开 URL」前移为独立按钮，保存位置与说明折叠收起。
- 播放历史从添加面板移到视频库右上角。音频库导航选中后保持音符列表图标，不再切换为另一种图案。
- 插件准备脚本独立解析 media_kit 路径，继续应用原有播放器释放顺序修复。

## 验证与边界

- 完整 Flutter 回归 **115 项通过**。
- 透明区域像素测试确认视频区域 alpha 为零、叠加控件仍不透明；原生显示位置与尺寸同步测试通过。
- 添加面板在 **320×568、1.5 倍字体**下，两个导入入口和两个直接播放入口均可在首屏点击；相关六项测试通过。
- 本轮开发 HAP 已多次覆盖安装并启动。用户在已连接真机上确认原生模式能够激活 HDR；这不代表所有编码、HDR 格式、设备或长时间播放均已验证。
- 原生输出仍为实验功能：需要 OHCodec 硬解支持；使用文本字幕，不支持 ASS 特效、GPU 超分与相关画质处理。具体承载方式和验证清单见 [OHOS HDR 说明](../third_party/media_kit_video/OHOS_HDR.md)。
- 本次 APP 使用 release 构建与项目 release 签名配置；未执行应用商店上传或发布。
- APP release 构建成功：`ohos-default-signed.app`；包内版本核对为 **4.0.0 / versionCode 199**。规范 unsigned HAP 更新时间为 **2026-09-06 18:31:30（北京时间）**，APP 更新时间为 **18:31:40**。
