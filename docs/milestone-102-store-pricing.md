# 里程碑 102：只使用华为商品价格

版本：4.0.2+255。替代里程碑 101 的固定金额兜底，继承其音频元信息和滑动优化。

- 删除年会员价格和首年优惠的固定金额、币种及商品 ID 判断。正常价格、优惠价均来自华为商品数据，保留嵌套原始 JSON 的解析。
- 华为明确返回不具备优惠资格时展示商店常规价格；明确具备资格且优惠字段有效时展示商店优惠金额、期限和后续续费金额。
- 缺少订阅信息、优惠资格未知、优惠字段无效或解析失败时显示“价格待确认”和重新加载提示，禁用购买。支付服务也检查同一条件，不能绕过页面保护下单。
- 购买确认前仍会刷新商店数据。若刷新后价格不完整，不进入确认或支付。

24 项价格、布局、支付生命周期及订阅确认回归通过。受影响 Dart 文件静态分析无 error。测试中的金额仅为样本数据，不是生产价格配置。

产物归档：`build/milestones/102-store-pricing`。安装使用 `tool/deploy_milestone.ps1 -Name 102-store-pricing`，覆盖安装保留应用数据。真实华为账号的商品返回及收银台金额仍需人工核对，本次不执行付款。
