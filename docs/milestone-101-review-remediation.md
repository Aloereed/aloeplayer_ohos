# 里程碑 101：华为审核整改

版本：4.0.2+254。对应会员首年优惠未注明、滑动响应 182ms、音频库艺术家列表进入元信息修改后闪退三项审核反馈。

## 修改内容

- 会员：从华为商品及其原始 JSON 读取优惠资格和优惠金额；年订阅明确展示“首年优惠金额、第二年起每年自动续费金额”。购买确认前重新查询商品，确认页采用本次查询结果。未知资格展示优惠条件和两种价格，不承诺账号一定能享受优惠。对于未返回优惠字段的人民币 72 元年会员，按本次审核确认的配置说明符合条件首年 36 元、后续每年 72 元；商店返回的有效优惠信息优先，币种或常规价变化时不采用该兜底。以后调整首年活动配置需同步更新此兜底。长文案区域可滚动，购买按钮保持可见。
- 元信息：删除共享音频格式变量、未经检查的空标签首项访问、按扩展名强制类型转换，以及读取歌词时安装的全局 SIGSEGV/siglongjmp 处理器。后者可能跳回已返回的栈帧。改用 TagLib 文件所有权管理和标准属性映射，串行保护读写，缺失标签返回空值，保存失败回传页面。原生使用 UTF-8，并兼容碟号 `2/12`、完整日期读取年份。编辑页释放控制器，异步完成后检查页面存活，保存前快照输入，限制重复保存和超范围整数。
- 滑动：音频列表文件大小改为异步读取并缓存；封面请求由可见组件持有，父组件重建不重复读取缺失封面，快速滚动时延后探测，组件销毁后取消延后任务。列表和编辑封面限制解码尺寸，编辑背景改为独立图像模糊和重绘边界，避免滚动内容参与整屏背景模糊。

## 验证范围

28 项 Flutter 回归全部通过，覆盖首年 36/续费 72、账号无资格/资格未知、商店变价、嵌套原始 JSON、短屏/大字体布局、支付生命周期、封面请求复用、编辑页快速退出和保存错误。受影响 Dart 文件静态分析无 error，保留原有风格和弃用提示。

原生测试全部通过：编译同版本 TagLib 1.13.1，调用生产使用的 `audio_tags.h`，覆盖 MP3/FLAC/OGG/WAV 的空标签、中文标签及歌词读写、完整日期、非法数字和文件，并执行 8 个线程合计 800 轮混合格式读写。测试源在 `test/native/audio_tags_test.cpp`；使用上游 `v1.13.1` 的 `tests/data`，工作副本输出到独立测试目录。

当前未连接鸿蒙设备。以上主机回归及构建验证不能替代 Mate 60 / HarmonyOS 6.1 的闪退复测、华为真实收银台资格核对和滑动响应检测；没有声明 182ms 已降低至某个实测值，也没有发起真实付款。
