## 设计依据

- [HarmonyOS 官方设计](https://developer.huawei.com/consumer/cn/design)：空间层次、互动区域的沉浸光感。
- [设计理念](https://developer.huawei.com/consumer/cn/design/concept/)：蓝白色彩、舒适圆角、轻拟物与立体空间。
- [HarmonyOS 6](https://consumer.huawei.com/cn/harmonyos-6/)：自然、纯粹的光感表达。

应用采用 Flutter 自绘视觉，不声称调用了系统原生沉浸光感 API。光影集中于导航与重点卡片，避免给每个滚动条目叠加实时模糊。

## 30 — 蓝白光感与悬浮导航

- 明确蓝白主色、深色夜蓝背景，拉开文字 / 背景对比，减少灰蓝铺底和描边。
- 手机导航使用圆角悬浮材质、局部模糊和边缘高光，取消 Material 选中胶囊；PC 侧栏使用轻盈选中层，统一线性图标。
- 媒体库首页使用柔和的蓝 / 紫 / 青光色，三个快捷入口排列；来源卡片按协议区分色彩，使用柔和阴影与轻拟物图标。
- 搜索框、弹层、按钮、视频卡片统一圆角与留白；常用设置及画质开关使用紧凑的圆润开关。
- 高对比度模式关闭导航模糊；小屏 2 倍字号点击测试通过。默认去除水波纹反馈，保留按钮悬停 / 按压状态。
- 全部 59 项测试通过，全局 Dart 静态检查无错误（仍有历史 lint）；7 张真实组件预览成功生成，已启用真实阴影，位于 `build/ui-review/index.html`。
- HAP 编译与 canonical unsigned 时间戳检查通过。无设备，最终触感、字体与模糊性能需要实际部署确认。
