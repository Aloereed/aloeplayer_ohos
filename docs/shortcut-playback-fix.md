# 快捷方式打开转圈修复

问题：视频库点击播放未等待权限激活；MPV 只读链接，依赖后台缩略图/时长加载恰好先激活权限。旧链接保存解码路径，再通过字符串拼接构造 file URI，文件名 #、?、百分号转义序列可改变原授权地址。本地错误缺少持久提示。

修复：

- 新链接保存系统选择器原始 URI，显示名称从 URI 路径段提取。
- shortcut_source.dart 统一新旧链接解析；旧绝对路径按路径段编码，保留字面百分号及 #、?，授权 URI 和播放器文件路径各司其职。
- 首页启动播放、MPV 打开/换片、旧播放器和媒体目录播放使用统一解析；播放主动等待授权，并检查普通本地目标能否实际打开。授权失败、空链接、读取失败及授权超过 8 秒均明确报错。无授权成功缓存，避免撤销权限后继续假设可访问。
- MPV 跳过其他失效链接，保持实际播放队列与历史路径索引一致。打开命令 20 秒超时，异常停止播放；失败界面停止转圈，提供重试/返回，支持短屏滚动。原生 HDR 自动回退仍优先执行。
- 保留原文件及既有链接，不批量改写用户媒体。正常旧链接无需重新添加；已撤销或失效的授权需要重新选择原文件。

验证：全量 Flutter 测试 240 项通过，3 项显式 SMB 回环按默认配置跳过。新增 7 项快捷方式测试覆盖等待授权、拒绝、超时、原生异常、空/失效目标、特殊字符与 HTTP；新增 1 项短屏错误界面测试。相关媒体库和缩略图回归通过。未访问用户鸿蒙设备，本次未更新安装包版本。
