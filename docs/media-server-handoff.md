最终完整 Flutter 回归：290 项通过、5 项按环境跳过。两个真实服务端测试单独启用并通过：Jellyfin 12.0.0、Emby 4.10.0.40，全部使用本机生成的媒体、账号和库。验证原画指定音轨、5 秒跳转后视频/PCM 解码哈希、HLS 转码跳转解码、外挂中文字幕、原文件下载及续传哈希；未连接用户的鸿蒙设备、NAS 或电视。

所有 Flutter/Hvigor 构建按项目要求在沙箱外运行。每次 HAP 和 APP 构建均验证规范路径 `ohos/entry/build/default/outputs/default/entry-default-unsigned.hap` 的新时间戳；debug HAP 先归档再构建 APP。APP 验证读取实际内嵌 HAP 的版本、QQ scheme 和 MPV 运行时段，不只检查文件名。MPV 未重新编译，保留此前已经验证的 OHCodec 定时输出修复。

## 验证边界

没有实机操作，因此不能将桌面真实服务器和编译结果等同于所有鸿蒙机型的解码、后台、手势或网络表现，也没有完成与所有专用 App 的同条件性能对比。旧服务端路径有兼容回退测试，但真实版本覆盖明确限于上述两版。

离线下载目前是原文件；不把转码 HLS 伪装成离线原文件。图片外挂字幕不独立下载，文本字幕有明确大小、条数与时限保护。HTTPS 证书验证保持开启，自签名部署需要设备正常信任证书。跨设备进度合并依赖时间比较，服务端接口无原子比较交换保证；本地存储失败或系统在检查点之前结束进程仍可能丢失最后几秒的位置。

部署后优先确认实际库的原画与转码、字幕/音轨切换、跨集连播，以及断网播放下载文件再联网刷新进度。遇到连接问题可从服务器菜单复制诊断摘要。各阶段的详细实现与复现证据见 `docs/media-server-milestone-73.md` 至 `docs/media-server-milestone-86.md` 和对应里程碑 `verification/` 目录。
