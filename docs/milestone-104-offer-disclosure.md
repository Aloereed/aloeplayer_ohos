# 里程碑 104：避免资格标志隐藏首年优惠

版本：4.0.2+257。用户确认 256 版审核环境的应用页面只显示常规价，而收银台显示首年优惠价。

此前代码把 `hasEligibilityForIntroOffer == false` 直接解释为不能使用优惠，完全隐藏商店返回的优惠。华为 SDK 注释及[官方 FAQ](https://developer.huawei.com/consumer/cn/doc/doccenter-operations/agc-help-countries-faq-0000002425264361)描述的是是否享受过同组推介促销，并说明由平台判断使用。缺少审核账号原始响应，不能确认是该标志还是嵌套返回导致本次现象，也不能仅据字段名反转含义。

本版只要商品包含有效推介优惠，就展示商店优惠金额、期限和常规续费金额，同时说明符合优惠条件时适用，不符合时按常规价开通。该标志不再用于隐藏优惠或承诺账号资格。无优惠商品仍直接使用商店常规价；优惠对象存在但价格或周期无效时继续阻止购买。

同时修复原始 JSON 查找：外层已有部分订阅信息时，仍检查内层原始 JSON 的优惠，避免把嵌套优惠当作不存在。金额均取自商品返回，无币种、金额或商品 ID 兜底。

27 项 Flutter 回归通过：覆盖所有资格标志、首年和续费价、资格条件提示、嵌套优惠、商店变价、无优惠月会员、无效字段拦截、布局与支付确认。静态分析无 error。

归档：`build/milestones/104-offer-disclosure`，包含调试签名 HAP、正式签名 Release APP、源码提交与校验清单。设备覆盖安装保留数据。未替审核账号下单，也未执行实际付款；仍需在审核环境核对商品返回与收银台。
