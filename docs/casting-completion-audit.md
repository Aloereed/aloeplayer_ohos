# 投屏目标验收记录

2026-09-09。目标来源：3 小时内新增播放页投屏入口、优化投屏界面及功能、修复无法投屏问题，并提供可回退里程碑。验证范围遵守不访问用户鸿蒙设备的约束。

| 要求 | 当前实现与验证依据 |
| --- | --- |
| 播放页入口 | MPV 视频手机/桌面、MPV 音乐、旧视频 Chewie 菜单和旧音乐底栏均调用 CastScreenPage；传递真实地址、位置、时长与音视频类型，MPV 网络媒体同时传入请求头。HAP/APP 编译验证集成。 |
| 发现和连接 | cast_integration_test 的本机 UDP 重叠扫描、延迟描述、大小写头；真实 HTTP 描述验证缺失 URLBase/SCPD、厂商 serviceId、相对/绝对控制地址、服务版本。发现按网卡独立、有界并发及扫描重试。 |
| DLNA 投送和控制 | 同一测试通过实际 SOAP 验证 InstanceID=0、XML 元数据、空成功响应、HTTP 500 中 UPnP 错误、701 有限重试和元数据降级、续播、暂停竞态、停止后恢复轮询、播放状态确认及不支持查询的接收端。 |
| 本地与网络媒体 | cast_media_relay_test 验证 HEAD/Range、令牌、中文路径、认证/重定向、HLS 层级与密钥/片段改写、跨源凭据隔离、编码、并发限制和关闭。真实桌面 FFmpeg 对加密 H.264/AAC HLS 完整播放和跳转解码，音视频哈希与原文件一致。 |
| SMB/WebDAV 投屏 | cast_network_source_test 使用真实认证 WebDAV HTTP 服务验证独立连接；smb_worker_test 验证配置和隔离，70 的显式 SMB2 回环三项全部通过，含浏览器断开后转发字节仍正确。无远程用户 NAS 访问。 |
| 系统投播 | CastView.ets 复用已有 AVSession，选择器类型匹配，真实接收端状态触发暂停本机，原生命令等待完成；test_system_cast.cjs 执行生产逻辑验证借用/新建、迟到控制器、断开、销毁和元数据保护；Hvigor 验证实际 ArkTS。 |
| 界面与操作 | 320px 深色页面及 1.3 倍文本的活动控制区测试；设备添加、错误复制、播放/暂停/停止/断开、进度及音量，网络设置后置。页面离开不关闭 DLNA 转发；系统投播关闭会释放独立 NAS 会话。 |
| 回归与性能 | 71 全量 Flutter 231 项通过、3 项显式 SMB 默认跳过；后续活动控制区新增测试及旧测试共 2 项通过；70 实际 SMB 三项另行通过。64MiB 回环流式转发 SHA-256 一致，测试数据和局限见里程碑文档。 |
| 交付与回退 | 68–71 均保留源码提交与归档 manifest。debug 签名 HAP 独立于 release APP；68 补充 debug 文件后未覆盖原 release 文件。包内版本与 MPV 运行时检查、全部归档 SHA-256、部署 DryRun 为交付检查。 |

验证日志随 71 的 verification 目录归档，历史 SMB 和性能证据在 70 的 verification 目录。构建产物以各里程碑 manifest 为准，不从会被后续构建覆盖的普通输出目录安装。

限制：未连接真实电视或鸿蒙设备，无法证明特定电视厂商固件、手机后台策略或实际 Wi-Fi 吞吐；不把模拟接收端和桌面解码结果称为真机通过。媒体按原格式投送，电视仍需支持原视频/音频编码。没有重新编译 MPV；先前无声 HDR 时钟修复继续在打包阶段验证。
