# 里程碑 87：锁定按钮自动隐藏

版本：4.0.1+240。

四个播放器共用的锁定/解锁入口闲置 3 秒后隐藏，触摸画面可重新显示。MPV 的未锁定入口同时受控制栏显示状态约束。锁定后轻点画面只唤出入口，仍需长按解锁，不会把触摸传给底层播放器。隐藏入口不解除手势、键盘和返回键拦截。长按期间取消隐藏计时，组件销毁时释放计时器。

验证覆盖入口自动隐藏、唤出不触发播放、长按解锁、控制栏隐藏时仍可唤出解锁入口，以及原有滑动、键盘、返回键拦截。未连接鸿蒙设备；真机请检查全屏和竖屏下轻点唤出、长按解锁以及连续切换视频。

构建保留独立的 debug 签名 HAP 和 release APP，存放于 build/milestones/87-player-lock-controls，不会覆盖旧里程碑。不重新编译 MPV。
