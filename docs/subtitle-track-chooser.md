# 里程碑 51：MPV 多字幕轨道列表

## 已确认的问题与修改

- 旧弹窗在打开时读取一次轨道列表，未订阅后续轨道发现事件。现改为订阅播放器 tracks 流并实时更新。
- 显示真实轨道总数与常驻滚动条；使用列表按需构建，无数量上限或语言筛选。
- 保留每条轨道的原始 ID、标题、语言和格式，选择时直接传递原轨道对象。
- “自动选择字幕”和“无字幕”独立展示，不再把 auto 误标为关闭字幕或重复作为内嵌字幕。
- 外部字幕加载按钮固定在底部；切换失败时留在弹窗显示错误。

## 验证

- `test/subtitle_track_dialog_test.dart` 通过：打开时 4 条英语轨道，随后更新为 48 条；滚动到第 48 条中文字幕并成功选择原 ID。
- 该测试使用模拟轨道事件，未使用用户报告的视频，不能据此确认特定媒体文件的全部轨道均已被底层播放器识别。

## 兼容播放器的独立限制

`lib/player.dart` 的兼容播放器菜单读取已提取字幕；`_extractRestAss` 受 `getSubtitleMany()` 设置限制（默认额外提取 0 条）。这与 MPV 的菜单不同。本次修改针对默认 MPV；若问题发生于兼容播放器，需要改为完整列举后按需提取，不能只靠本次 MPV 菜单修改解决。
