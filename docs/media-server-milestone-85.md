# 里程碑 85：连接诊断与可操作错误提示（4.0.1+238）

服务器列表菜单、服务器首页增加连接诊断，分别检查地址与版本、当前账号权限、媒体库读取和目录分页。每个检查显示本次接口响应耗时，独立呈现结果，单步最长 6 秒；重新检查和离开页面都会取消旧检查。全部使用读取接口，不修改服务器设置或创建播放会话。

登录对话框增加“诊断地址”，只提交地址与所选服务器类型，不发送用户名、密码或已有令牌；未登录时仅执行公共版本接口检查。发现 Jellyfin 公共标识与所选 Emby 类型不一致时给出调整提示。账号诊断明确显示播放、下载、视频和音频转码权限，不把没有返回的权限字段当作允许。

统一补充证书验证失败、连接超时、反向代理上游 502/504、请求限流 429、服务器启动或繁忙 503 的提示。诊断不关闭 TLS 验证。可复制的诊断摘要只包含类型、版本、检查结果与耗时，不包含配置名称、服务器地址、用户 ID、媒体名称、令牌或响应正文。

验证包括真实 Jellyfin 12.0.0 与 Emby 4.10.0.40 的四项读取检查，并同时回归播放、字幕、下载、音乐和离线进度。模拟服务器验证权限限制、登录失效、错误页面、摘要脱敏、取消前与在途取消；320 像素页面验证多行权限信息和重新检查。接口诊断不等同于视频带宽或设备解码性能测试。未访问用户设备，MPV 未重新编译，debug HAP 和 release APP 独立归档。
