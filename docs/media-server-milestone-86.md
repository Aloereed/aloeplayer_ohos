# 里程碑 86：在线播放断网进度恢复（4.0.1+239）

在线播放进度报告失败时，将可寻址媒体的最后位置写入已有持久化待同步队列；恢复连接后可与离线观看进度使用同一套补同步逻辑。后续在线播放报告成功时，仅清理采样时间不晚于该成功报告的旧记录，避免旧确认删除后来保存的新进度。

报告携带位置采样时刻，网络排队和超时不会把旧位置伪装成最新位置。保留一条在途报告加一条最新待发送报告的有界队列、停止优先、会话与代理清理。不可 seek 的直播不写入该恢复队列。持久化辅助操作最多等待 1 秒，不让存储异常无限阻塞网络报告和播放器关闭；本地存储故障或系统在检查点之前直接结束进程仍无法保证最新位置落盘。

测试覆盖进度 POST 失败后落盘、后续成功后清理、停止 POST 失败后从队列补同步，以及旧确认保留较新的记录。真实 Jellyfin 12.0.0 和 Emby 4.10.0.40 注入一次进度请求失败，验证位置暂存后被后续成功停止报告正确确认；同时回归目录、诊断、下载、外挂字幕、音乐、剧集与离线同步。未访问用户设备，MPV 未重新编译；debug HAP 与 release APP 独立归档。
