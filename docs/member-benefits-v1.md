# 第一版会员权益

本版沿用现有月、年会员及服务端验单链路，增加具体权益，不增加会员等级。

| 能力 | 免费范围 | 会员 / 本机体验 |
| --- | --- | --- |
| 画质 | 原始画质、高清缩放、FSR 均衡、手动色彩调节 | Anime4K 动漫超分、FSR 高画质、去色带、动漫 / 老片 / 高清预设 |
| 来源 | SMB / WebDAV 不限数量；Jellyfin / Emby 各 1 个；已有超额配置保留 | 添加更多 Jellyfin / Emby 来源 |
| 下载 | 单文件下载、队列、断点续传、系统允许的后台下载 | 选择当前 SMB / WebDAV 列表中的多个文件，一批最多 100 个 |
| 基础体验 | 播放、字幕、画中画、续播、书签、海报库均保留 | 不另设限制 |

不宣传尚未实现的自动刮削、跨设备同步、自动跳片头、下载规则或 Jellyfin / Emby 离线下载。

## 提示与体验

- 不在启动、播放、切页时自动弹促销窗口。只有用户主动操作受限功能才显示说明，可直接取消，也可以先查看会员权益。
- 在会员页或功能说明中主动点击“免费体验 7 天”后开始本机体验，无需登录或支付，不创建华为订阅，不会自动续费。
- 本机体验状态持久保存，正常重启不会重新计时；已结束的体验不能通过按钮重开。本版不是服务端按账号限制的试用，清除应用数据、修改本地状态不能由此机制彻底防止。
- 本机体验和华为商品自身的促销试用相互独立；华为实际付费方案仍使用商店价格、优惠资格及自动续费说明。
- 会员页列出真实权益、免费范围和到期行为。FSR 是空间超分，不是 AI 修复；设备和片源限制沿用画质页说明。

## 到期和旧数据

- 来源额度按协议判断：SMB / WebDAV 完全不受会员数量限制；Jellyfin / Emby 非会员各最多新增至 1 个。已有超额配置始终可播放、编辑、重新登录和移除，修改协议时检查目标协议名额。旧版本 `freeSourceSlots` 总额度字段不再使用，体验与画质兼容状态保留。
- 旧 `mpv.image-enhancement.v1` 中已保存的 FSR 高画质、去色带分别保留使用资格。新版本体验或会员期间的设置不会被误认成旧权益。
- 到期不主动切换当前播放画质、不弹窗。下次初始化播放器时受限画质回落至免费档，保留存储中的设置；主动修改设置仍正常保存。
- 已加入队列的下载不再检查会员，可以完成、暂停、恢复。到期不删除文件、记录或来源。
- 权益读取失败时播放器保留原始画质，基础播放不依赖新增权益存储成功。

## 实现与验证

- `MemberAccess` 集中处理付费有效期、本机体验和迁移。付费权限实时读取现有 `MembershipService`，不修改支付或兑换规则。
- SMB / WebDAV 配置和媒体服务器存储共用串行队列，在写入媒体服务器及凭据之前分别检查 Jellyfin / Emby 额度，防止并发新增及修改协议绕过限制；文件服务器不检查会员。
- 画质服务与批量下载服务也检查权限，不能只绕过界面按钮调用。已经接受的任务不会因执行途中到期而中断。
- 批量下载去重并跳过已有任务 / 完成记录，汇总加入、跳过及失败数量；单文件入口可按需重新下载。
