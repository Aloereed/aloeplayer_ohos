# 里程碑 82：音乐专辑与连续播放（4.0.1+235）

音乐专辑默认按碟号、曲号、名称排序；浏览普通目录保持名称排序。筛选对话框增加碟号与曲号排序，支持手动指定名称或其他顺序，重置后恢复随目录类型选择的默认顺序。筛选和收藏条件仍可组合。

播放具有 AlbumId 的音频时，播放器支持专辑内上一首、下一首和自动播放下一首，沿用已有睡眠定时、单曲循环和切换期间防重复操作机制。仅为即将播放的曲目协商媒体源，不沿用上一首的 source ID 或音轨索引。专辑分页按原始游标读取，跨碟、跨页，过滤不同专辑条目；最后一首不自动回绕，异常重复页不会无限请求。连续播放遵循专辑曲序，不受浏览页临时筛选或显示排序影响。

服务器音频显式传递 audio 类型，修复无扩展名音乐标题在播放历史中被识别为视频的问题；音乐的首尾提示和自动连播开关使用“首”而非“集”。缺少 AlbumId 的独立音频仍可播放，但不猜测同名专辑或跨库连播。
