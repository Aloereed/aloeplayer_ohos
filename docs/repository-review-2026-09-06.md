# AloePlayer 鸿蒙版：仓库分析与本轮改进

本轮以“无设备、约三小时、分阶段提交和打包”为约束。安装包构建通过只能说明 Dart、ArkTS、链接和签名流程通过；解码器、音频焦点、文件授权、后台保活、投屏设备兼容性仍须真机验证。

已按第二轮实测反馈继续处理：17–28 里程碑覆盖旧缩略图、媒体来源入口、PiP 重建、移动 / PC 视觉整理、复制 / 快捷方式说明和 mpv FSR 超分。最新实现与验证边界见 [第二轮记录](round2-milestones.md)。

## 主要问题及处理方向

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 播放状态分散在 MPV、系统视频和两个音乐服务中 | 切换媒体、退出页面、后台恢复容易丢进度或重复响应 | MPV 等待初始化、订阅释放、播放检查点；统一睡眠定时器与稳定媒体身份 |
| 网络播放把临时 HTTP 地址当作媒体身份 | 重启后历史地址失效，续播不能重连原服务器 | 用服务器 ID 和文件路径建立稳定身份，历史打开时重新连接并生成代理链接 |
| Range 边界、HEAD、服务共享生命周期不统一 | 拖动失败、下载接缝多一个字节、关闭共享中断本机流 | 通用范围解析、独立 LAN 监听、分监听器令牌、WebDAV Content-Range 校验及真实 HTTP 测试 |
| 密码放在 SharedPreferences JSON 中 | 明文持久化；并发迁移或保存还可能丢配置 | 鸿蒙 Asset Store 桥接、成功后再删除明文、串行读改写和迁移失败测试 |
| 同步枚举、排序反复 stat、全库加载封面 | 大目录卡顿、内存随媒体数量增长 | 异步枚举、修改时间快照、后台音频解析、可见封面加载、内存与磁盘配额、缩略图任务限流；SMB 同步 FFI 由独立 worker 执行 |
| 下载绑定浏览器临时连接 | 中断后不可恢复、退出页面影响下载 | 独立下载连接、任务持久化、实际偏移续传、源修订校验、原子入库、暂停取消等待资源释放 |
| 本地库以文件名浏览为主 | 多季剧集和已有 NFO/海报难以利用 | SQLite 增量海报索引、NFO 解析、搜索、剧集筛选、同剧播放队列 |
| 播放工具与媒体服务器入口不足 | 字幕不同步、书签和章节难以复用 | 每媒体字幕/音频偏好、命名书签和 AB 片段、章节、Jellyfin/Emby 直播放与进度上报、系统画中画接续 |
| 可运行版本与源码缺少一一对应的留档 | 无设备时难以定位何时引入问题 | 每个里程碑 Git commit、签名/未签名 HAP、构建时间、SHA-256、来源清单 |

## 功能入口

- 媒体库主页：SMB、WebDAV、Jellyfin / Emby 来源卡片与统一添加入口；继续观看、下载任务和海报库在主页文字按钮中。
- 网络文件更多菜单：下载到本地、显式生成局域网共享链接、停止共享。
- MPV 设置顶部：超分与画质、系统画中画；其余列表包含字幕同步/书签/章节、定时停止。画质提供 FSR、高清缩放、去色带与色彩调节，默认关闭。
- 视频库“添加视频”：复制与不复制的快捷方式明确并列，保留 Downloads/包名/Videos 复制策略；视频更多菜单可重建缩略图。
- 海报库读取本地媒体同目录的 `同名.nfo` / `movie.nfo`，以及 `同名-poster.jpg`、`同名.jpg`、`同名.png`、`poster.jpg`、`folder.jpg`。不自动联网抓取元数据。
- 下载完成文件放入原有 Videos 或 Audios 的 Downloads 子目录，下载任务可直接播放。

## 后续应结合真机继续验证的方向

1. 播放器底层仍包含多种实现。本轮共用媒体身份、定时器和偏好服务，没有直接替换全部解码管线。彻底统一播放引擎、硬解失败自动切换和 HDR 行为，需要覆盖真实编码样本及退出生命周期。
2. Jellyfin/Emby 当前实现文件直播放。实时电视、服务端转码、码率协商和复杂多版本媒体不在当前连接器支持范围内。
3. SMB/投屏吞吐、长时间后台传输、PiP 窗口恢复、ASS 效果及声音焦点需要 NAS 和设备联测。系统 PiP 使用系统解码器，其格式支持和字幕效果与 MPV 不同。
4. 历史遗留分析警告尚未全部清理。检查范围为应用 `lib` 和 `test`，排除了归档示例和未启用 SMB 原型；本轮优先处理会影响行为、数据和资源释放的问题。
5. 不建议在没有设备时同时升级所有依赖或大幅重写原生播放器。本轮已锁定当前验证过的依赖和构建链，并通过离线锁文件构建；后续再逐项引入升级。

具体提交、各阶段验证结果及回退注意事项见 [第二轮记录](round2-milestones.md)与 [第一轮记录](overnight-milestones.md)。
