# 芦荟播放器 4.0.2 更新日志

相较 4.0.1（221），本次更新带来隐私空间、播放防误触，以及媒体库与投屏体验的多项改进。

## 新增功能

- **隐私空间**：支持设置 6 位密码、导入媒体副本、搜索和管理私密内容，离开或切到后台自动锁定。私密播放不记录普通播放历史。文件不额外加密，导入后原文件仍保留。
- **播放器防误触**：播放时可锁定操作，长按解锁；锁定按钮会自动隐藏，轻点画面即可唤出。

## Emby / Jellyfin 媒体库

- 完善首页继续观看、下一集、最新内容与收藏入口，支持详情、季集浏览及观看状态管理。
- 增加类型、观看状态、收藏筛选与排序，改善搜索和分页，减少重复条目和旧请求干扰。
- 完善多版本视频、音轨、外挂字幕及原画／转码播放兼容性。
- 支持上下集切换、跨季续播与自动连播；音乐按碟号和曲号排序，支持连续播放。
- 支持原文件下载、断点续传及离线续播，可保存外挂文本字幕，并单独补下载失败的字幕。
- 改善在线与离线观看进度保存，恢复连接后补同步，减少断网造成的进度丢失。
- 新增连接诊断，帮助检查服务器地址、账号权限和媒体库访问问题。

## 播放与投屏修复

- 修复本地视频与媒体库视频切换后可能只有声音、画面黑屏的问题。
- 修复部分视频硬件解码播放结束后，其他视频一直缓冲、无法继续播放的问题。
- 修复关闭循环模式后仍自动播放下一项的问题。
- 恢复并完善 HDR 直出，改善无音轨或音轨不受支持时的播放速度异常。
- 修复部分本地文件快捷方式打开后一直加载的问题。
- 修复系统投播按钮不显示、停留在“正在准备投播”等问题，可直接打开系统设备选择界面。
- 改善 DLNA 投屏连接与播放状态判断，修复部分局域网环境下向 Kodi 投送本地视频时一直加载的问题。
- 完善带鉴权的网络视频、HLS 及 WebDAV／SMB 媒体投送，减少切换页面或断开媒体库连接对投屏的影响。

## 使用体验

- “添加视频”中的旧 WebDAV 下载入口改为直接前往媒体库，统一浏览 WebDAV／SMB 内容。

部分播放、转码和下载能力取决于服务器权限及接收设备支持。
