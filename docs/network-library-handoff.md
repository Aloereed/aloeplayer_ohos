## 优先验证

1. **SMB 根目录**：主机只填 NAS 地址，起始路径填 `/`，应列出真实磁盘共享，包含可访问的隐藏磁盘共享，过滤打印机和 IPC 项。主机 URL 已包含共享名时，根目录表示该共享内部。服务器禁止 IPC$/共享枚举时，使用“打开路径”输入 `/共享名/目录`，或在配置中直接指定已知共享；不能枚举不再阻塞已知共享的连接。
2. **连接配置**：保存前“测试连接”会实际读取选定目录。验证普通账户、`DOMAIN\用户名`、匿名，以及要求签名的服务器；加密要求不会静默降级。IPv4、裸 IPv6、方括号 IPv6 与独立端口字段均有覆盖。
3. **WebDAV 路径与证书**：URL 填完整服务入口，起始路径相对此入口，避免重复填写 `/dav`。根目录无权限时指定有权限的子目录。自签名证书可配置从 NAS 管理端核实的叶证书 DER SHA-256 指纹；证书更换后需更新指纹。未配置指纹时仍走系统证书验证。
4. **媒体读取**：验证中文、空格、`%`、`#` 文件名，字幕匹配，多共享切换，超过 4 GiB 的视频及尾部拖动。播放同时浏览大目录，观察是否发生卡住或串流。服务器忽略 Range 时支持从头顺序读取，非零位置拖动会明确提示，可改用下载后播放。
5. **大目录与下载**：检查自然数字排序、搜索和目录前进后退。测试下载暂停、恢复、重启，以及服务器文件被替换后的版本检查。短暂 429/502/503/504 会在媒体响应体开始前有限重试；持续失败仍显示可复制的错误详情。旧任务如提示远端已变化，应重新创建任务。

## 已验证的范围

- 最终全量回归 **208 项通过**；另有 2 项真实 SMB 回环测试默认跳过，已分别在 IPv4 和 IPv6 显式运行通过。覆盖真实 SMB2 共享枚举、跨共享、签名、匿名、域账户、完整读取及错误凭据。
- 静态分析无 error/warning；存在既有 info 提示。最终签名 HAP 构建成功，规范未签名产物时间为 `2026-09-09T04:10:23.5236123+08:00`。
- 本机 HTTP 两万项 WebDAV 目录解析约 **281–311 ms**，期间事件循环继续响应；字幕索引避免逐媒体扫描全部字幕。SMB 浏览与媒体读取使用独立工作线程，读取缓冲按服务器协商上限调整，最多 1 MiB。
- 原生夹具验证 4 GiB 以上读取偏移和 5 GiB 文件长度；OHOS aarch64 头文件 ABI 静态编译通过。回环、夹具与分析日志随里程碑保留。

这些是本机和静态验证结果，不代表真机吞吐量或所有 NAS 品牌均已验证。没有实际鸿蒙设备测试；本机 Docker 引擎未运行，未开展真实 Samba SMB3 加密组合测试。SMB1、WebDAV NTLM/Kerberos/OAuth/表单登录不在当前实现范围。SMB 协商与认证有 30 秒截止时间，但原生 DNS 解析仍受操作系统行为影响。
