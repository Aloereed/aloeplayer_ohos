# 里程碑 72：隐私空间与播放器防误触（4.0.1+225）

用户确认：私密媒体不额外加密。功能从设置页的“隐私空间”进入，也可在视频菜单选择“复制到隐私空间”。

## 隐私空间

- 使用应用 support 私有目录，独立索引和随机文件名，不进入普通视频/音频扫描根目录。导入为副本，原文件保留；界面明确说明，避免误以为导入后原文件已隐藏。
- 6 位 PIN 使用项目已有的安全凭据存储（鸿蒙 HUKS 通道）；不写入媒体索引、普通偏好设置或日志。连续 5 次错误锁定 30 秒，次数/冷却持久保存；不存在凭据时不能覆盖已有空间重设 PIN。
- 导入采用文件复制、长度与 SHA-256 校验、临时文件改名和独立索引提交；失败不删除源文件。提供私密区内搜索、删除副本和修改 PIN。
- 未解锁不能访问文件；切后台、离开空间、私密播放返回后锁定。授权尚未完成时发生锁定，迟到结果不能重新打开空间。
- 私密播放复用 MPV，明确 privateMode；不写普通历史/播放偏好，不初始化系统音频媒体通知，不开放截图、投屏、画中画，不在后台继续播放。进入后台关闭上层私密播放和对话框，返回 PIN 页。
- 鸿蒙进入空间前启用 Window.setWindowPrivacyMode，退出恢复。声明 ohos.permission.PRIVACY_WINDOW；原生失败会阻止打开空间。使用本地 SDK API 声明，并参考华为官方权限配置说明：https://developer.huawei.com/consumer/cn/doc/doccenter-dev-faq/faqs-arkui-1344 。这不等同于媒体文件加密。

## 防误触锁定

MPV 视频、旧视频、MPV 音乐、旧音乐播放器统一提供屏幕侧边锁定按钮。点击后阻断整个播放器的触摸/拖动/快捷键和返回，保留“长按解锁”。旧播放器已有返回处理同时检查锁定状态，避免返回键先改变全屏状态。媒体继续播放；系统硬件功能与系统导航不属于应用内触摸锁定的控制范围。

## 验证与交付

全量 Flutter 249 项通过，3 项显式 SMB 测试默认跳过。新增验证涵盖 PIN 拒绝与持久限流、复制字节与原文件保留、凭据丢失、索引越界、迟到授权、修改密码、安全存储异常、后台隐藏片名，以及锁定的触摸/拖动/快捷键/返回/长按解锁。原生生产逻辑测试验证窗口保护启用/恢复/错误传播。未访问用户设备；实际窗口保护、原生视频表面与系统返回手势由用户部署验证。
