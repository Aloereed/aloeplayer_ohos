# 里程碑 79：媒体服务器下载与离线观看（4.0.1+232）

Emby/Jellyfin 详情新增“下载原文件”，媒体服务器首页新增下载与离线观看入口。下载采用播放设置中选择的媒体版本，不把转码画质设置误当成原文件格式；未选版本时采用服务器首选源。下载复用既有队列、后台服务、暂停/重试、空间检查、临时文件和完成后原子改名。

任务只持久化服务器 ID、媒体/版本 ID、文件名、大小与修订信息；每次恢复重新从安全凭据存储获取登录信息，不持久化访问令牌或临时本机播放 URL。独立连接与本机受限通道随任务取消、暂停或结束关闭。

HEAD 不可用时兼容最小范围查询。完整响应和续传校验 Content-Length、Content-Range、ETag/修改时间以及内容编码；拒绝服务器忽略非零 Range、同大小版本替换、范围错位或不适合直接下载的清单。缺少可靠版本信息时明确拒绝非零续传，避免拼出损坏文件。下载原始文件内容不额外加密。

已完成文件可从下载页离线观看。历史记录继续播放会先匹配同服务器、同媒体的本地完成任务，并核对文件存在与大小；命中后不需要服务器连接。清理下载任务记录会清除这项自动匹配关联，原文件仍保留并可从本地媒体目录播放。

验证：真实 Jellyfin 12.0.0 和 Emby 4.10.0.40 的完整原文件下载、从第 4096 字节续传分别与生成源文件的 SHA-256 一致；原画解码、HLS 转码、音轨、中文字幕、续播、收藏和剧集查询回归通过。故障测试覆盖忽略 Range、错位 Content-Range、版本变化、HEAD 不支持、队列落盘、凭据不进入任务 JSON、离线副本匹配与文件损坏后不命中。现有 WebDAV/SMB 下载和投屏通道测试同时回归。

本阶段下载原文件及其内嵌轨道；外置字幕打包、持久离线观看进度补报和整季批量下载仍需继续完善。未访问鸿蒙设备，后台下载持续性与实际系统通知仍需部署验证。MPV 未重新编译，debug HAP 与 release APP 独立归档。
