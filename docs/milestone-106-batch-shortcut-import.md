# 里程碑 106：批量添加快捷方式提示优化

版本：4.0.2+259。

用户反馈一次添加多个文件时，每个文件都会显示一条“快捷方式已添加，视频未复制，原文件请保留在当前位置”，提示排队持续遮挡界面。原实现还会在每次创建快捷方式后重新扫描视频库。

本版将快捷方式添加按整批处理：全部完成后只刷新一次视频库、显示一条简短汇总。成功时显示“已添加 N 个快捷方式”，2 秒后自动消失，也可手动关闭。同名文件跳过，单个失败继续处理其余文件，跳过与失败数量合并进最终提示。取消选择不显示结果。添加期间禁用重复添加入口，并固定本批次的保存目录。

“原文件保留位置”的说明继续保留在添加面板的“保存位置与说明”中。

验证：导入面板与快捷方式授权相关的 13 项现有 Flutter 测试通过；视频库文件静态检查 0 个错误，仍有 12 个现有警告。此次尚未安装到真机，100 文件批量导入的实际界面与耗时待设备验收。

产物归档目录：`build/milestones/106-batch-shortcut-import`。

- `entry-default-signed.hap`：Debug 签名、Release 编译，用于设备安装测试。
- `entry-default-unsigned.hap`：同次 HAP 构建的规范未签名产物。
- `ohos-default-signed.app`：Release 签名、Release 编译，用于发布提交。
- `manifest.json`：源码提交、版本、构建时间、产物大小与 SHA-256 校验值。

两个签名包使用同一版本与实现。HAP 必须先归档再构建 APP，避免 APP 构建覆盖工作目录中的 HAP。构建与校验记录随里程碑保存。

上一里程碑为 `105-reversed-offer-flag`，对应版本 4.0.2+258。
