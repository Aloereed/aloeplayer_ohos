## 21 — mpv 超分与画质增强

- 播放器设置新增“超分与画质”：原始画质、高清缩放、FSR 均衡 / 高画质，去色带与亮度 / 对比度 / 饱和度 / 伽马。
- FSR 1.0.2 EASU + RCAS 着色器随包离线提供，固定上游版本与 SHA-256，保留 MIT 许可；不需要首次联网下载。
- 修复 media_kit_video OHOS 的 setSize 缺失，使 GPU 实际输出更大画面。单边最多 2 倍，均衡最高 1080p、高画质最高 4K，保持比例，不强行缩小高分辨率源。
- 默认全部关闭；读取验证 mpv 属性是否接受，失败恢复原配置；HDR / RGB 避开 SDR luma 着色器。
- 五项逻辑测试通过；原生输出补丁确已应用，HAP 编译与时间戳校验通过。
- 实机必须验证：720p 片源切换 FSR 后的锐度、流畅度、发热；4K / HDR 不应变色；关闭效果应恢复输出；反复退出播放器不得崩溃。
- 参考：[mpv 渲染选项](https://mpv.io/manual/stable/)、[FSR 上游及许可证](https://gist.github.com/agyild/82219c545228d70c5604f865ce0b0ce5)。本项尚无 GPU 实机验证，不将编译通过视为画质或性能结论。
