# 里程碑 83：离线观看进度与下载入口（4.0.1+236）

从下载页播放 Emby/Jellyfin 媒体时保留服务器条目身份，与历史继续播放共用记录；按用户点击的具体下载版本打开，不会替换成另一个已下载版本。打开前检查文件存在且长度匹配，缺失或不完整时明确提示。NAS 下载仍保留本地播放行为。

离线播放每次播放器保存进度时，把最新位置写入本地待同步队列。队列以配置 ID、账号 ID 和服务器地址指纹隔离，不存令牌或串流 URL；应用重启后继续保留。退出离线播放器时尝试同步，进入或刷新该服务器首页时也会补同步；首页显示等待同步或完成状态。没有可读取的账号配置时文件仍可播放，保留本地历史，但不能补报到已删除的账号。

Jellyfin 使用更新 UserData 的接口并为旧路径保留 404/405 回退；只更新播放位置和时间，接近实际结尾（至少 99%，且距结尾不超过 1 秒）时标记完成，不改变收藏。Emby 使用官方客户端采用的 Sync/OfflineActions 与稳定 action ID，由服务器判断观看完成状态。同步前读取 LastPlayedDate，若服务器记录更新则保留服务器状态。此比较依赖两端时钟，接口没有原子比较交换保证，不能完全消除其他设备恰在读取与写入之间更新的竞争。

每轮同步有 12 秒总期限，连接失败后保留队列等待下一次连接；已删除条目的 404 不阻塞其他条目。正在同步的旧记录成功后仅删除对应 revision，期间新增进度不会被删除。该阶段补齐离线文件播放的补报，在线会话中断的报告仍使用原有有界队列。

真实 Jellyfin 12.0.0、Emby 4.10.0.40 验证 9 秒恢复点、收藏保留、过期离线记录拒绝和播完标记；电影、音乐、字幕、下载与剧集测试同步回归。持久化测试验证失败后重建队列、账号隔离、无凭据落盘、在途写入保护与冲突丢弃，下载测试验证两个入口的媒体身份一致和文件损坏检查。未操作用户设备，MPV 未重新编译；debug HAP 与 release APP 独立归档。
