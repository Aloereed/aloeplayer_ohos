# 里程碑 95：恢复直接系统投播按钮

版本：4.0.1+248。

用户复测里程碑 94 后，按钮仍停在准备转圈。此前以自定义构建器刷新解释问题的判断没有得到真机验证，条件挂载方案也未解决问题。

按用户要求恢复原先直接调用 AVCastPicker 的入口：不设置 ready 条件、不禁用、不延迟挂载，不通过平台视图对象订阅按钮状态。沿用最初入口的系统默认 sessionType 选择行为。固定蓝色图文自定义外观仅负责可见性，点击由系统组件处理。媒体会话准备和错误继续通过现有 Flutter 状态通道显示，不阻止用户打开系统面板。

删除无用 ready、sessionType 和 pickerListener 通知代码。保留此前媒体元数据与投播控制逻辑、循环关闭修复和上游原版 MPV。

构建：./build.ps1 hap debug -Offline -Locked -NoVersionBump。debug 签名、Flutter release 编译。

真机待测：进入系统投播即可点击蓝色选择投播设备按钮并打开系统面板；连接设备后验证媒体播放。尚未将本包安装到设备，不将编译通过视为真机通过。
