# 里程碑 103：恢复无优惠月会员购买

版本：4.0.2+256。修复里程碑 102 将“无推介优惠”误判为“优惠信息不完整”的回归。

华为返回有效订阅周期且 introductoryOffer 缺失或为 null 时，直接使用商品常规价格，允许购买，不要求可选的优惠资格字段。规则适用于所有订阅商品，不按月会员 ID 或固定金额放行。

优惠对象存在时继续检查资格、价格和周期；空对象或非法对象不作为无优惠处理。订阅信息缺失仍禁止购买。年会员优惠及购买前刷新逻辑保持不变，金额完全来自华为数据。

27 项 Flutter 回归通过，包括优惠对象缺失/null与资格缺失/true/false的组合、无优惠月会员进入支付服务、无效优惠拦截、年会员首年和续费价、会员布局及自动续费确认。测试模拟打开支付，不进行真实付款。

HAP 归档：`build/milestones/103-no-offer-subscription`。覆盖安装保留应用数据，设备版本应为 4.0.2+256。用户已反馈上一版年会员正常，本版修复月会员可购买性，真实账号收银台金额仍需核对。
