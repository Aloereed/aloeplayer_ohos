# 兑换码与华为会员兼容检查

后端提交 `a675e76`，客户端提交 `5604451`，里程碑 45 / 3.1.1+189。

用户决定：买了会员后不要再使用兑换码。本次按“有效付费会员期间禁止兑换；到期后允许”实施。

- 兑换码直接由用户中心处理，不调用华为验单、购买或确认发货。仍需登录应用账号并连接用户中心。
- 现有有效付费会员（华为订阅含试用，或其他实付订单）会被服务端拒绝兑换，码的使用次数和状态不改变。
- 客户端设置页显示限制原因，不能打开兑换输入；服务端独立检查，旧版客户端也不能绕过限制。
- 兑换码会员仍可以继续兑换并累加；只延长兑换码来源的记录，绝不延长华为控制的记录。
- 单独的兑换码记录不会被华为续订、退款或到期同步改写。
- 已有较长兑换码会员再购买较短华为会员时，验单返回当前同类权益的最长到期时间，客户端不会短暂缩短会员显示。
- 华为订单自身的截止时间单独返回 purchase_expiry_date，用于判断付费期间的兑换限制；不影响既有兑换时长。

覆盖后端 ZIP 的 backend 文件，保留 .env 后按原方式重启；本包累计包含此前 IAP 更新。
