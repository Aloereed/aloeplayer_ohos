# 里程碑 84：外挂字幕离线保存与收尾恢复（4.0.1+237）

原文件入库后自动保存所选媒体版本的外部文本字幕，字幕文件名保留语言和轨道区分，文件以临时名称写入、检查大小后改为最终名称。任务记录保存文件路径和长度，不保存凭据或服务器字幕 URL。下载页显示已保存字幕数量，可单独补下载缺失或损坏的字幕；成功文件重试时不会重复下载，补下载前重新确认原媒体版本未变化。

本地播放只使用仍存在且长度匹配的已保存字幕；播放器字幕列表可选择所有已保存的语言，并隐藏外部字幕完整路径。字幕加载失败给出提示，保留视频播放；服务器离线媒体不再用目录自动扫描覆盖已验证的字幕选择。

支持 SRT、ASS、SSA、VTT 文本字幕，TTML/mov_text 通过服务器 SRT 输出尝试转换。图片字幕暂不独立下载，原文件里的内封字幕照常保留。外挂字幕失败不会把已经完整下载的视频改成失败，支持以后补下载。为防止异常服务器无限输出，单次最多处理 32 条，单条 32 MiB、合计 128 MiB、45 秒网络保存期限；连接和数据等待也设有超时。错误网页、压缩响应、空文件、超长或截断结果不登记为有效字幕。

下载最终改名之前写入收尾标记。若应用恰在改名之后、完成状态保存之前退出，重启只有在最终文件大小匹配且临时文件已不存在时恢复为完成；临时文件仍存在时继续保持暂停，不把半成品当成下载成功。取消动作在最终改名前再次检查；已完成任务收到后台暂停通知时不退回未完成状态。

真实 Jellyfin 12.0.0、Emby 4.10.0.40 验证外挂中英文字幕的内容、双语文件保存与重试去重，并回归电影版本、音轨、原文件下载哈希、转码、剧集、音乐及离线进度同步。模拟故障覆盖 HTML 登录页、超限响应、损坏字幕补下载；测试收尾恢复和多条外部字幕选择。未操作用户设备，MPV 未重新编译。debug HAP 与 release APP 独立归档。
