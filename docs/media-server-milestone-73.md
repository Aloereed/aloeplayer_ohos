# 里程碑 73：Emby/Jellyfin 浏览可靠性（4.0.1+226）

搜索、刷新与目录切换使用可取消的独立查询代次，迟到的结果或错误不能覆盖新目录。搜索输入防抖 300 ms，提交立即执行；返回、清空与目录切换同步搜索框。播放协商同样支持取消，用户更改搜索或返回后不再打开旧视频。

分页使用服务器 TotalRecordCount 和原始响应条目数推进 StartIndex；列表按媒体 ID 去重。短页但仍有总数时继续加载；空页或服务器反复返回同一页时停止，避免无限请求。接近列表底部自动加载，保留手动入口；下一页失败保留已有列表和游标，允许重试。

验证包括控制请求顺序的竞态测试，以及真实本机 HTTP 接口的 Emby 反向代理前缀、中文搜索、分页参数、认证头、取消播放请求、Jellyfin 登录与观看上报。未连接用户服务器或鸿蒙设备。首页、详情、选集、完整播放协商和离线等仍按总路线继续推进，本里程碑不是整个目标的完成声明。

交付保留 debug 签名 HAP 与 release APP，构建使用 release Flutter 编译；先独立归档 HAP，再构建 APP，避免覆盖可部署包。
