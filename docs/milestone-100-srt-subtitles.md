# 里程碑 100：纹理模式 SRT 字幕修复

版本：4.0.2+253。

修复 MPV 纹理输出下内嵌、导入 SRT 字幕不显示的问题。OHOS 视频控制器显式设置 `sub-fonts-dir=/system/fonts` 和 `sub-font=HarmonyOS Sans SC`，为没有自带字体的文本字幕提供系统字体；同步旧控制器补丁。此前仅设置了 OSD 字体。保留 ASS 样式与直出字幕链路。

用户于 2026-09-10 对修复测试包反馈“可以了”。该反馈对应 4.0.2+252 修复测试包；本里程碑递增构建号至 253，字幕实现相同。新增发布产物的构建与静态校验不等于重新完成设备实播。

归档目录：`build/milestones/100-srt-subtitles`，包含签名 HAP、Release APP、构建日志及记录版本、源码提交与 SHA-256 的清单。

里程碑编号进入三位数，索引和部署脚本改为按数字排序并接受三位及以上编号，保证 `latest` 正确选中里程碑 100。
