# 4.0.0

- MPV 默认使用「自动（推荐）」硬件解码，对应 `hwdec=auto-safe`。未保存过该设置及无效值使用新默认值；用户明确保存的关闭／强制自动设置保留。
- 启动页版本号直接读取安装包信息，避免固定文案与实际版本不一致。
- 海报库按作品展示，剧集按季聚合并按集数排序。支持电影、剧集、音频及未看完筛选，片名／文件名／年份搜索，名称、最近更新和年份排序。
- 点击海报进入详情，支持简介、文件位置、选季选集、继续播放及从头播放。播放队列包含完整剧集，不受搜索结果或季筛选截断；不可访问的其他集跳过，当前选中文件无法访问时显示提示。
- 读取现有播放记录，展示观看位置和已看完状态；退出播放后更新。剧集优先继续最近未播完的一集，其次选择尚未看完的下一集。
- 可通过系统文件选择器添加本地快捷方式，不复制原媒体。扫描应用 Videos / Audios 目录，包括下载子目录及媒体快捷方式。
- 支持同名 NFO、movie.nfo、tvshow.nfo、季目录继承、S01E01 / 1x02 文件名识别；大小写不敏感查找 JPEG / PNG / WebP 海报。没有 NFO 也能显示和播放。
- 兼容动漫发布文件名，如 `[字幕组] 片名 - 03 [WebRip]` 和 `片名 [01][WebRip]`，聚合时去除字幕组前缀。首次进入自动进行增量扫描。
- 无海报的视频按需生成本地缩略图，遵循「禁用缩略图」设置；单任务队列、内存缓存和最多 64 MB 的磁盘缓存。缩略图失败仍显示占位封面，不阻塞播放。
- 增量扫描可取消，取消后保留原索引及已扫描结果；分别清理成功扫描目录中的失效索引，缺失／不可访问目录的记录保留。损坏 NFO 不阻断扫描，索引打开失败可重试。

海报库仍为免费功能。本版使用本地资料，不包含自动联网刮削、TMDB 匹配或远程媒体库统一索引。

验证：`test/catalog_test.dart`、`test/catalog_layout_test.dart` 和 `test/nfo_metadata_test.dart` 覆盖扫描、取消、恢复、聚合、续播及小屏／横屏／大字体布局。版本与设备安装结果以本次构建及 SDK 部署日志为准。
