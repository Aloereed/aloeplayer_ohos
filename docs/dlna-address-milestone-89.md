# 里程碑 89：修复 DLNA 广播错误媒体地址

版本：4.0.1+242，包含 87 的锁定按钮和 88 的系统投播按钮修复。

用户反馈：同一个本地视频，系统投播到电脑 Kodi 正常，非系统 DLNA 只转圈。

确认的代码错误：MediaCastService._localAddress 在选择 DLNA 设备后使用 Socket.connect(receiver).address 作为转发媒体 URL 的主机。当前 Dart VM 在出站连接时用目标地址初始化该属性，不能当作 getsockname；于是媒体 URL 指向接收端自身，而转发服务实际运行在手机。系统投播无 activeDevice 时从本机网卡选址，不触发此分支。

修复：枚举本机网卡，优先 Wi-Fi，通过显式 sourceAddress 绑定验证接收端可达性，返回该本机源地址。按地址族匹配，失败尝试其他接口，总探测时间限制为 8 秒；没有可用地址时明确报错，不返回接收端地址。手动选择网络仍按用户选择执行。

回归：用 127.0.0.1 和 127.0.0.2 两个自有回环地址分别模拟发送端与接收端，验证返回地址与接收连接观察到的源地址一致。原测试均用同一个 127.0.0.1，掩盖了此错误。补充无可用地址失败测试，并运行投屏、转发、界面与系统桥接测试。

不连接或操作用户 Kodi、鸿蒙设备。代码根因已修正，实际同一视频回测仍待用户确认。包目录 build/milestones/89-dlna-source-address，独立保存 debug HAP 与 release APP。
