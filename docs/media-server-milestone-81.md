# 里程碑 81：媒体库筛选与排序（4.0.1+234）

浏览页新增筛选与排序：电影、剧集系列、单集、音频；全部/未看/已看；只看收藏；名称、添加时间、首映时间、评分、时长升降序。筛选作用于当前浏览范围及其子目录，重置恢复原有目录浏览；搜索可与筛选组合。当前浏览会话内保留筛选，摘要显示生效条件。

切换条件取消旧请求并从第一页加载。筛选对话框取消时不会丢失待执行的搜索；清除条件同步当前搜索文字。详情返回后，已不匹配收藏/观看条件的条目立即移除，修正分页游标和总数；当前页被移空时自动补齐，不把“还有后续结果”误显示为无内容。新的浏览动作会取消旧详情刷新，防止迟到结果覆盖新筛选。

验证：320 像素宽筛选对话框的类型、观看状态、收藏、评分排序和重置；旧请求取消/迟到结果、条目移除时取消在途分页并补齐。真实 Jellyfin 12.0.0 和 Emby 4.10.0.40 验证电影观看状态筛选的结果集合，递归单集类型查询与五种排序字段请求；播放、下载权限、完整/续传哈希、字幕、音轨和剧集查询同时回归。
