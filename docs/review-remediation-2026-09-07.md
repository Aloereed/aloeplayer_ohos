## M1：问题定位（完成）
- URL 入口直接将整段输入传给播放器，未提取链接、未解释网页与直链区别。
- 首次隐私页与外层分页指示器共用 Stack，底部发生遮挡。

## M2：功能整改（完成）
- 视频库及播放器共用 URL 输入框：提取分享文本、多个链接主动选择、保留签名参数、验证 HTTP 状态及网页 Content-Type；播放异常解释原因与处理方法。
- 首次隐私页不显示外层分页控制，后续控制避开底部安全区。
- 购买页显示首次价格、优惠说明、常规续费金额及周期，提供会员服务说明、自动续费协议、取消流程和客服。
- 每次购买前单独确认金额与自动续费，默认不勾选，用户主动勾选后才可进入华为支付。免费体验仍不自动转付费。
- 设置及会员页增加客服入口：邮箱、复制、发送邮件、在线反馈；邮件无法唤起时提示替代路径。
