# 里程碑 48：HDR 标识修复与播放方式收敛

版本：**4.0.0+200**。

## 交付内容

- 视频库列表补回 HDR 标识；网格继续显示 HDR 角标。
- 开启或切换 HDR 检测方式后通知视频库刷新。检测缓存区分文件与检测方式，关闭检测和检测失败不再缓存为非 HDR；关闭缩略图不再阻止 HDR 检测。
- 保护刷新期间的异步任务，旧任务完成时不移除新任务。
- 隐藏「FFmpeg软解」和「系统播放(仅音频软解)」。读取旧设置时自动迁移到 MPV 并保存；写入旧选项也回落到 MPV。迁移统一覆盖视频和音频入口。

## 验证与打包

- 完整 Flutter 回归 **124 项通过**，包括手机大字体下的 HDR 标识、检测设置通知、两种旧播放方式的持久迁移以及其他现有方式的保留。
- APP 使用 release 签名配置，HAP 使用 debug 签名配置。沿用项目构建脚本约定，两者 Flutter 编译模式均为 release，HAP 可用于调试签名设备安装。
- 构建、包内版本、SHA-256 和设备覆盖安装记录随安装包归档；部署保留应用数据。
- 原生 HDR 输出仍为实验功能，限制沿用里程碑 47。本次未进行应用商店发布。
