## 部署

本轮重建使用 Flutter `3.41.10-ohos-1.0.0` / Dart `3.11.5`，保留项目已有调试签名和 API 23 最低要求。签名包含的设备授权沿用本机原有配置。

连接设备、启用开发者模式后，在仓库根目录运行：

```powershell
.\tool\deploy_milestone.ps1
```

脚本验证 HAP 的 SHA-256 后部署最新包。指定旧版或设备：

```powershell
.\tool\deploy_milestone.ps1 -Name 27-thumbnail-rebuild-file-actions
.\tool\deploy_milestone.ps1 -Name 25-ffmpeg-thumbnail-fallback -Target '设备ID'
```

可先加 `-DryRun` 查看动作。脚本使用 `bm install -r -d` 保留应用数据并允许从高版本回退；API 23 起，调试签名应用支持该降级参数。[OpenHarmony 官方 bm 文档](https://github.com/openharmony/docs/blob/master/zh-cn/application-dev/tools/bm-tool.md#安装命令install)

如果设备授权、签名类型或系统版本不匹配，脚本会停止并保存输出，不会自动卸载。可用相应目录的 unsigned HAP 按现有 DevEco 签名流程重新签名。不要先清数据：历史、配置和迁移状态是定位问题的重要线索。

## 建议检查顺序

本轮优先检查以下五项，再按后面的完整表检查原有功能：

| 本轮重点 | 操作与预期 |
| --- | --- |
| 旧视频缩略图 | 保持缩略图设置开启，进入旧目录并滚动；系统取帧失败时应尝试 FFmpeg。仍缺失时，在视频更多菜单点“重新生成缩略图”；检查重名、竖屏和快捷方式。旧缓存或原文件不会被批量删除。 |
| 本地添加说明 | 点击“添加视频”：看到“选择文件并复制”和“不想复制？添加快捷方式”。复制仍存入 Downloads/com.aloereed.aloeplayer/Videos，原文件保留；快捷方式不复制视频。小屏顶部直接可选快捷方式，移除时再次说明原视频保留。 |
| 媒体库与界面 | Jellyfin / Emby 和 SMB / WebDAV 在媒体库主页平级显示；测试旧账号、添加 / 编辑 / 移除。切换手机 / PC 模式、窄窗口、大字号、深色模式，检查视频 / 音频搜索和更多操作；PC Ctrl+1–4 切页，Ctrl+F 搜索视频。 |
| 画中画 | 先用常见 H.264 + AAC MP4，再试 MKV / 网络视频；从播放器设置顶部进入，应自动开启。测试暂停、回原播放器、立即返回、连续开关、定时停止。失败应显示阶段 / 错误，准备有 30–35 秒上限。系统解码器不支持的格式会报错并可返回 mpv。 |
| FSR 超分 | 播放器设置顶部“超分与画质”：用 720p SDR 对比原始 / FSR 均衡，检查输出尺寸、边缘、流畅度和发热；再测试 1080p→4K 档。默认关闭，关闭或恢复默认应立即还原；HDR / RGB 跳过 SDR 着色器。去色带和色彩调节分别测试。 |

FSR 是离线空间超分与锐化，不是 AI 帧生成；单边最多 2 倍，均衡封顶 1080p、高画质封顶 4K。系统 PiP 使用 AVPlayer，不继承 mpv 的 FSR、ASS 和倍速效果。没有实机时无法确认 GPU 兼容性、实际画质与功耗；设备不接受画质选项时会回退默认并显示说明。

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 启动与退出 | 本地 MP4、MKV 各播一次，拖动、返回，重复 5 次 | 无崩溃、黑屏残留或继续出声 |
| 播放队列 | 点击列表中非第一项；切换排序；下一项/上一项 | 实际播放与标题、选中项一致 |

| SMB / WebDAV | 中文/空格/百分号文件名；拖到文件后半段；切换服务器 | 路径正确、范围读取正确、没有旧服务器串流 |
| 共享与投屏 | 播放中生成 LAN 链接，再停止共享；尝试投屏和拖动 | 本机播放不受共享开关影响；外部只能读授权文件 |
| 音乐与大目录 | 快速切目录、切艺术家/专辑，滚动封面；修改标签后刷新 | 最新目录保持正确、界面可响应、封面按需出现 |
| 工具 | 字幕延迟、语言、章节、书签、AB 片段、定时停止 | 设置生效，重新打开仍有书签/偏好；定时后保持暂停 |
| 下载 | 下载后暂停/继续；断网再重试；取消；退到后台 | 断点续传、完成后可播、取消清临时文件；后台被拒绝/取消时有说明 |
| 海报库 | 放同名 NFO/海报，扫描两次；中途取消 | 标题/剧集显示正确，增量扫描不清空旧索引 |
| Jellyfin / Emby | 登录、翻页、搜索、打开影片、退出 | 直播放正常；服务端能看到播放进度；失效会话可重新登录 |
| 系统 PiP | 从 MPV 设置进入、开启、暂停、回原播放器；锁屏控制 | 同时只有一个解码器出声，返回位置正确，暂停不被自动恢复 |

先完成本地播放和网络拖动，再测试新增能力。系统 PiP 使用系统解码器，ASS 效果和 MPV 倍速偏好不自动迁入；Jellyfin/Emby 当前不提供直播或服务端转码。

记录“第一个异常版本 / 上一个正常版本、文件编码或协议、触发步骤、错误截图或日志”。可先运行 `hdc hilog > build\device-hilog.txt` 再复现，结束时 Ctrl+C；分享日志前注意其中可能包含本地文件名和服务器地址。

## 重建与核对

```powershell
.\build.ps1 hap debug -Offline -Locked
.\tool\index_milestones.ps1 -VerifyHashes
```

`debug` 指签名配置，Flutter 产物仍为 release 模式。`-NoVersionBump` 可保留源码版本号；如果原生构建复用了旧 HAP 时间戳，脚本会拒绝把它当作新产物。首次在新机器构建需要联网准备缓存，不应使用 `-Offline`。
